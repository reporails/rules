# Project Instructions (Override)

This is a Python web application using FastAPI and PostgreSQL.

## Commands

- `pytest tests/ -x --tb=short` — run tests with fail-fast
- `uvicorn app.main:app --reload --port 8080` — start dev server on 8080

## Style

- Use type hints on all function signatures
- Follow PEP 8 naming conventions
- Maximum function length: 30 lines (stricter than base)
